# 模型及评估范围

发布版本：v1.0.0。模型为纯 MuJoCo 数据训练的 SmolVLA，发布时没有重新训练或修改权重。

- 权重 SHA256：`117974341c69adb4e65e47fca8de221eccd192d4cf4fe588b95665ff8e10d1b0`。
- 归一化统计 SHA256：`390831801e3a3ddc10c6ba37d0a9570804cdbad794ac64fe8e41313e54c081c8`。
- LeRobot 提交：`0b067df57d21d3a02d6c511f1609172fa39ac29b`；Transformers 4.57.6。
- FP32、原生10步去噪、噪声种子731；仅标准逆归一化，无任务相关输出后处理。
- 初始图像640×400、初始6个关节角；绝对角度目标，单位rad；108步、10Hz、10.8s。
- 训练/验证/测试为96/16/32条纯仿真示范，空间单元隔离；模型选择未使用测试结果。真机视频只用于早期可见动作阶段核对，未混入训练。

SmolVLA 继承通用预训练视觉语言基座；本任务微调数据来自仿真，不能声称整个模型的预训练也只使用仿真数据。基座为 HuggingFaceTB/SmolVLM2-500M-Video-Instruct 架构；发布包的完整策略检查点已包含所需的保留层权重，backbone文件夹只需配置和tokenizer。

## 成功条件

沿用扩大测试前锁定的 `paper_tolerance_v1`：末2秒双指每个0.5ms物理步均有>0.01N接触力；方块与纸面>0.01N接触的时间比例≥95%，最长中断≤50ms。还要求完整张开、抬升≤4mm、没有臂触纸或非法自碰撞、mimic误差<0.005rad、接触穿透<3mm。

指尖触纸单独记录，不直接判失败。运行结果中的 `success` 与 `failure_reasons` 均依据上述条件生成。

当前模型评估：32个场景32/32，另有256个位置+64个配对外观场景320/320。它们仍在窄工作区内，不代表模型完全解决泛化问题。

发布版六个固定位置只用于接入验收，不是额外独立测试集，也不将6/6加到此前320例中。位置、相机、光照、方块尺寸、起始姿态明显变化时结果可能下降。这里没有运输/抬升任务，也没有真实木材或真实舵机动力学标定。
